Tested code · synthetic data · held-out years

We trained a model and tested it on years it never saw

The code is public. It generates made-up utility data for 900 assets over 8 years, trains on 2019 to 2024, and tests on 2025 and 2026. Everything below comes from running that code. Because we wrote the data generator, these numbers show the pipeline works. They do not show how real equipment behaves.

5,400 / 1,800Training rows and held-out test rows. The test years come after the training years, so the model cannot peek.

Read this before quoting a number.
  • Only 84 failures in the test years, so the percentages are rough.
  • Regions differ in age and storm exposure by design in our generator, so a risk-based policy is bound to help. A real utility may or may not look like this.
  • This is one run of one made-up world. A real pilot would use the client's records.
  • The Live model page runs the same trained model in your browser. Its results match the Python results to about 7 decimal places.

Run it yourself

The code, data files and 6 tests are in the Asset-readiness repository on GitHub. Install the requirements, run python run_all.py, then python -m pytest.
