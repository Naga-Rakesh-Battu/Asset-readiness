Databricks · how the pipeline maps onto the platform

The same pipeline, running as a Databricks notebook

We turned the prototype into one notebook, run on Databricks, that builds the tables, trains the model and checks the stocking plan using Databricks building blocks: Delta tables, MLflow and Spark SQL.

Status, plainly

Run end to end on Databricks Free Edition (serverless compute) on 11/24/2026. All cells passed, and the results match our local Python and Spark runs. It is still synthetic data, and this is a prototype, not a client deployment.

Step by step

StepWhat happensDatabricks piece
1 BronzeRaw asset history lands as is: 5,000 assets, 8 years, 40,000 rows.Delta table
2 SilverChecks for duplicates and missing values. The notebook stops if a check fails.Delta table plus assertions
3 GoldSplit by time: train 2019 to 2024, test 2025 and 2026.Delta tables
4 ModelAge-only baseline and gradient boosting, with settings and scores recorded for each run.MLflow tracking
5 ScoresEvery asset gets a failure risk, saved as a table.Delta table
6 SparesSame total spares, placed by asset count or by model risk.PySpark
7 CheckShare of real failures that had a spare in the same region.Spark SQL

What the Databricks run gave

Model on held-out years

AUC 0.753 against 0.725 for the age-only rule.

Spread by asset count

80% of failures (369 of 461) had a local spare. 131 spares unused.

Placed by model risk

90.5% of failures (417 of 461) had a local spare. 83 spares unused.

These match the Evidence page and our local runs. The data is synthetic and we wrote the failure formula, so this shows the pipeline works, not real-world value.

What Databricks would add for a client

  • Governed tables, so the client controls who sees which data (Unity Catalog).
  • A model registry and a schedule, so retraining runs as a monitored job.
  • Real client tables in place of our synthetic ones. Most of the work would be here.

Try it

  1. Make a free Databricks account (Free Edition).

  2. Import databricks_notebook.py into the workspace.

  3. Attach compute and choose Run all. It takes a few minutes.
